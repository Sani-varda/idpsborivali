- **Affiliation:** CBSE Curriculum (K-12)

## 🚀 Running the Website Locally

You can run any static HTTP server from the root directory:

### Using Python:
```bash
python -m http.server 8000
```
Open **`http://localhost:8000/`** in your browser.
